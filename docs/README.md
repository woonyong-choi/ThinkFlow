# 문서

daphnis의 설계 문서다. 문서는 한국어로 쓴다. 처음 사용하는 사람은 사용법부터 읽고, 구현을 고칠 때는 아키텍처를 읽는다. 그림 표현별 사용법은 레퍼런스 문서에 있고 사용자가 읽는 문서라 합쇼체로 쓴다. 문서는 현재 계약과 확인한 증거만 적는다. 진행 기록과 검수 영수증은 GitHub 이슈에 남기고 문서에 시간순으로 쌓지 않는다.
