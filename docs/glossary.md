# 용어

이 프로젝트에서만 쓰는 말이다. 업계에서 널리 쓰는 말은 넣지 않는다.

| 용어 | 뜻 | 원어와 코드 이름 |
|---|---|---|
| 관계 그래프 | 카드 안에 이름과 관계를 작은 알약과 선으로 그린 그래프다. | `graph`, `minigraph` |
| 글 상자 | 점에 붙어 함께 움직이는 작은 글이다. | `chip`, `data` |
| 단계 | 탭 하나로 보이는 흐름 한 덩어리다. | `step` |
| 멈추는 시간 | 점이 도착한 뒤 다음 박자까지 기다리는 시간이다. | `DWELL` |
| 박자 | 단계 안에서 한 번에 일어나는 이동, 밝히기, 카드 바꾸기, 설명 바꾸기의 묶음 단위다. | `beat`, `seg` |
| 이동 | 점 하나가 선 하나를 따라 지나가는 일이다. | `hop` |
| 장면 | 도형, container, 선의 그림 좌표 모음이다. | `scene` |
| 조용한 선 | 쓰는 단계에서만 보이는 선이다. | `quiet` |
| 점 | 선 위를 움직이며 무엇이 오가는지 보이는 파란 원이다. | `packet` |
| 카드 | 박자마다 내용이 바뀌는 도형 안의 점선 칸이다. | `card`, `show` |
| 흐름 | 원본 안 `#@` 줄 전체가 적은 애니메이션 순서다. | `flow` |
| 흐름 문법 | `#@` 줄을 적는 규칙이다. | `#@` |
