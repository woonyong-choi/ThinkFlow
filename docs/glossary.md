# 용어

이 프로젝트에서만 쓰는 말이다. 업계에서 널리 쓰는 말은 넣지 않는다.

| 용어 | 뜻 | 원어와 코드 이름 |
|---|---|---|
| 관계 그래프 | 카드 안에 이름과 관계를 작은 알약과 선으로 그린 그래프다. | `graph`, `minigraph` |
| 그림 검사 | 배치한 장면과 모든 박자 상태에서 화면 오류를 찾는 검사다. | `check` |
| 그림 종류 | 원본의 첫 문장이 정하는 그림의 갈래다. 문서 스킬의 다섯 그림과 다르다. | `flow`, `sequence`, `state`, `data`, `chart` |
| 글 상자 | 점에 붙어 함께 움직이는 작은 글이다. 선 라벨과 다르다. | `chip` |
| 단계 | 탭 하나로 보이는 시간 흐름 한 덩어리다. | `step` |
| 도착 규칙 | 점이 도착하는 도형의 카드는 도착할 때, 나머지 카드는 박자 시작에 바뀐다는 규칙이다. | `cardsAt` |
| 드러내기 | 차트에서 숨어 있던 계열을 보이게 하는 박자다. | `reveal` |
| 그룹 | 도형과 다른 그룹을 담는 테두리 영역이다. | `group` |
| 박자 | 단계 안에서 한 번에 일어나는 이동, 밝히기, 카드 바꾸기, 설명 바꾸기의 단위다. | `beat`, `segment` |
| 선언 | 원본에서 도형, 그룹, 선, 상태, 테이블, 계열, 값을 적는 부분이다. | 없음 |
| 시간 흐름 | 원본에서 첫 `step`부터 끝까지, 움직임을 적는 부분이다. | `timeline` |
| 시간표 | 시간 흐름을 박자마다 시작 시각, 끝 시각, 완전한 상태로 편 목록이다. | `schedule`, `segs` |
| 연결점 | 선이 도형이나 그룹 경계에 닿는 자리다. | `port` |
| 이동 | 점 하나가 선 하나를 따라 지나가는 일이다. | `hop` |
| 장면 | 배치가 끝난 도형, 그룹, 선의 그림 좌표 모음이다. | `scene` |
| 점 | 선 위를 움직이며 무엇이 오가는지 보이는 원이다. | `packet` |
| 조용한 선 | 그 선을 처음 지나는 박자부터 그 단계 끝까지만 보이는 선이다. | `quiet` |
| 카드 | 박자마다 내용이 바뀌는 도형 안의 점선 칸이다. | `card`, `show` |
